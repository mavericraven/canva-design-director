# Example Slide Structures

**The Hero Slide**
- Background: Full-bleed high-contrast image (Darkened by 30%).
- Typography: White, bold, center-aligned, absolute middle.
- Logo: Subtle, bottom right.

**The Metric Slide**
- One massive number (e.g., "300%").
- One line of context below it.
- Vast negative space. No bullet points.
