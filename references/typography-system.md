# Typography System

- **San Francisco / Helvetica Neue / Inter:** Preferred for modern, clean communication.
- **Hierarchy:** - Title: Heavy/Bold, tight tracking.
  - Subtitle: Medium/Regular, contrasting size.
  - Body: Regular, minimum 14pt (digital) or readable scale, loose leading (1.4 - 1.5).
- **Contrast:** Ensure WCAG AA compliance minimum for text against backgrounds.
